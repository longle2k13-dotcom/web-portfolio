## About This Project
This is the first website that I built and designed by myself. It marks my first step in practicing web design. The website includes three pages: Home, Projects, and Contact. I used CSS Flexbox and Grid to build the layouts, as well as an HTML form for the Contact page.
## What I Learned
I learned how to build the basic structure of a website and add images and content to different pages. I also learned how to use CSS to control the layout, colors, spacing, and transformations of different elements.
## Next Steps
If I had more time, I would use JavaScript to make my Contact form more interactive. For example, I would check if the user entered their name, email, and message correctly before submitting the form.
